3. Get the real URL. The host is a routing key, not public DNS. Its auto-assigned *.volceapi.com
   domain is only visible in the APIG console, never through kubectl:

     https://console.volcengine.com/veapig -> service list (host = {{ include "dataverse.apig.host" . }})

   ⚠️ Do NOT verify by curling the CLB IP with a Host header: APIG answers 401 with error code
      010002 that way for every host, working ones included. Test the assigned domain instead.

{{- if .Values.catalog.tokenAuth.enabled }}

Issuing a catalog token. It is signed inside the catalog container, so the secret never leaves the
cluster — which also means whoever can exec into that pod can sign one:

  kubectl -n {{ .Release.Namespace }} exec {{ include "dataverse.rerunName" . }}-0 -c catalog -- sh -c \
      "rerun server generate-token --secret \"\$(cat /run/secrets/server_token_secret)\" \
          --user <name> --permission read --expiration 90d \
          --server-host <gateway domain> --server-host {{ include "dataverse.rerunName" . }}-headless.{{ .Release.Namespace }}.svc.cluster.local"
{{- end }}
