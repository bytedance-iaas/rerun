服务的部署与运维见上一级目录的 [02-deploy.md](../02-deploy.md) 与 [03-test.md](../03-test.md)。

- [01-viewer.md](01-viewer.md) — 用浏览器 viewer 打开并查看 TOS / HuggingFace 上的数据集。
- [02-catalog.md](02-catalog.md) — 从 Python 连接 catalog server,注册数据集、训练直读取数。

图片放 `images/`,需要标注的图同时保留原图(`-raw`)和标注版(`-annotated`)。
